# 문제은행 암기 (PWA)

아이폰 홈 화면에 설치해서 쓰는 문제은행 암기 앱입니다. 서버 없이 정적 파일로 동작하고, 오프라인에서도 열립니다.

## 기능
- **오늘의 학습**: 간격 반복(라이트너 상자). 맞히면 다음 복습까지 간격이 늘고(0→1→3→7→14→30일), 틀리면 처음부터 다시
- 틀린 문제는 같은 세션에서 4문제 뒤에 한 번 더 출제
- 보기 순서 섞기(설정에서 끄기 가능), 섞었을 때는 채점 후 원본 번호 표시
- "옳지 않은 것" 강조, 해설의 숫자(금액·일수·개수) 색 강조
- 오답노트, 순서대로/랜덤 풀기, 모의고사, 정답 훑어보기
- 앱이 꺼져도 풀던 세션 이어서 하기

## 진도 보관
- 폰 안(localStorage)에 자동 저장 + 브라우저에 삭제 방지 요청(`navigator.storage.persist()`)
- 설정 → **백업 파일 저장**: 공유 창에서 "파일에 저장 → iCloud Drive"
- 설정 → **백업에서 복원**: 저장한 JSON 파일 선택
- 백업한 지 3일이 지나면 홈 화면에 알림

## 매뉴얼
- 홈 → '온라인 평가 시스템 매뉴얼': 목차·검색, 쪽마다 옮긴 글 + 원본 화면 이미지
- 원문: `source/manual.txt`, 이미지: `manual/pNN.jpg`

## 영역 추가
1. `source/<영역id>.txt`에 문항 원문 작성 (형식은 `tools/build_data.py` 맨 위 설명 참고)
2. `tools/build_data.py`의 `AREAS`에 영역 추가
3. `python3 tools/build_data.py` 실행 → `data/*.json`, `data/index.json` 갱신

진도는 `영역id:문항번호`로 저장되므로, 기존 영역의 id와 문항 번호는 바꾸지 마세요.
